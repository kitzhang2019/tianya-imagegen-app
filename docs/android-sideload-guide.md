# Android 侧载安装指南（Debug APK）

> 适用：从 GitHub Actions 构建产物 `tianya-imagegen-android-debug` 里下载的
> `app-debug.apk`。这是 **Debug 包**（用标准 debug key 签名），可直接安装，
> 不需要任何账号、不需要 Google Play、不需要开发者模式。

最后更新：2026-11-13。改编自之前管理站 App（vps-manager）的同名指南。

---

## 1. 你需要准备的东西

- 一台 Android 手机（Android 7.0 / API 24 及以上；Capacitor 8 的 minSdk 是 24）
- 从 GitHub 下载的 `app-debug.apk` 文件
- 能把 APK 传到手机的办法（见第 2 步）

## 2. 把 APK 传到手机上（任选一种）

| 办法 | 做法 |
|---|---|
| 数据线 | 手机连电脑，选「传输文件」，把 `app-debug.apk` 拷到手机 Download 文件夹 |
| 微信 / QQ | 电脑上发给「文件传输助手」，手机上点开文件 → 右上角「…」→ 用其他应用打开 / 保存到手机 |
| 网盘 / 邮箱 | 上传到网盘或发到自己邮箱，手机上下载 |
| 浏览器直下 | 在 GitHub Actions 产物页用手机浏览器直接下载（需登录 GitHub 账号） |

> 注意：微信里直接点 APK 常常提示「不支持打开」，要先点右上角菜单选
> 「用其他应用打开」或「保存到手机」，再到文件管理器里安装。

## 3. 安装步骤

1. 手机上打开**文件管理器**，找到 `app-debug.apk`，点一下。
2. 第一次安装非商店应用时，系统会弹窗提示「出于安全考虑，您的手机目前不允许安装
   未知来源的应用」或类似文字：
   - 点弹窗里的**设置**，会跳到「安装未知应用」页面；
   - 找到你刚才用来打开 APK 的那个应用（文件管理器 / 微信 / 浏览器），把它后面的开关**打开**；
   - 返回，再点一次 APK。
   - 不同品牌叫法不同：小米叫「安装未知应用」，华为叫「外部来源应用安装」，
     三星叫「安装未知应用」，OPPO/vivo 在「安全」设置里。核心都是：**给「打开 APK 的那个
     应用」授权**，不是给整个手机开一个总开关。
3. 点**安装**，等几秒完成，点**打开**即可。
4. 首次打开如果提示网络权限，点允许。

> 装好后可以回到设置里把「安装未知应用」的开关再关掉，不影响已装好的 App。

## 4. 如果弹出 Play Protect 警告

Google Play Protect 扫描到非 Play 商店安装的包时，可能弹窗：

- **「Play Protect 已屏蔽此应用」/「此应用有害」**：点**仍要安装**（或「详细信息」→
  「仍要安装」）即可。这是 debug 包没有经过 Play 签名导致的误报——包是我们自己
  从 GitHub Actions 构建的，来源可信。
- **「发送到 Play Protect 扫描」**：可以选「不发送」，不影响安装。
- 如果你的手机装了第三方杀毒软件，也可能有类似提示，同样选「仍要安装/信任」。

> 判断标准：APK 必须是你自己从 GitHub Actions 产物页下载的。如果 APK 来路不明，
> 不要点「仍要安装」。

## 5. 装好之后：填 Kaggle Token

打开「天涯生图」→ 右上角设置 → 填 **Kaggle 用户名** 和 **Kaggle API Token**
（Kaggle 设置页 API Tokens 栏点 Generate New Token 生成的那串以 KGAT 开头的 Token）。
Token 只存在手机本地。画廊推送密钥可选，不填也能生图。

## 6. 更新 App

- 新版本发布后，重复第 2–3 步：下载新的 `app-debug.apk`，直接安装即可，
  旧数据（设置、任务记录）一般会保留；如果安装时提示签名不一致，先卸载旧版再装。
